Limites

  • Jugements de pertinence et faits requis rédigés par les développeurs ; juge automatisé OpenAI, non humain.
  • Split exposé non aveugle.
  • Les profils Anthropic utilisent adaptive thinking / effort medium / plafond 8192, différents du plafond 800 de Phase 7.
  • Les coûts JEV sont estimés ; les coûts LLM sont mesurés sur l’usage fournisseur.
